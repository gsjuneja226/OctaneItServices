# Octane IT Services - Official Web Platform

A production-grade, multi-page web platform for **Octane IT Services**, an IT services and full-funnel digital growth agency based in Ludhiana, Punjab, serving clients pan-India. Built with Next.js 14 App Router, React 18, and Tailwind CSS in a light, premium aesthetic.

---

## 🚀 Key Features & Service Pillars

1. **01 Technical & Local SEO**
   - Ludhiana local map pack optimization (Google Business Profile) & Pan-India commercial search ranking.
   - Core Web Vitals 120-point technical audit & search-intent keyword silo architecture.
   - Sub-tags: `TECHNICAL AUDIT`, `LOCAL PACK`, `CONTENT`.

2. **02 PPC & Performance Marketing**
   - Google Search, Display, PMax & Meta Ads (Facebook & Instagram).
   - Focused strictly on **Cost Per Lead (CPL)** and ROAS attribution, not vanity impressions.

3. **03 AI SEO & GEO (Generative Engine Optimization)**
   - Brand entity validation and structured schema designed to get your business cited inside ChatGPT, Perplexity Pro, and Google Gemini answers.

4. **04 Digital Marketing & Omni-Channel Strategy**
   - Synchronized quarterly growth blueprints across social media distribution, content marketing, and automated email sequences.
   - Sub-tags: `SOCIAL`, `CONTENT`, `EMAIL`.

5. **05 Video Marketing & Short-Form Production**
   - Scripting, on-site 4K shooting, sound design, and kinetic typography for Instagram Reels, YouTube Shorts, and paid video ads.

6. **06 Modern Website & Application Development**
   - Modern Next.js 14 and MERN stack engineering.
   - Sub-second performance, role-based internal management dashboards, customer portals, and custom CRM integrations.

7. **Extended Agency Capabilities**
   - Social Media Handling & Community Management
   - AI Workflows & Zapier/Make Automation Bots
   - WordPress & Shopify E-Commerce Storefronts with Indian payment gateways (Razorpay, Cashfree, UPI)
   - Physical Exhibition Pamphlets, Tri-fold Brochures & Print Collateral
   - High-Impact Content Writing & Technical Copywriting

## 📄 Pages Included

- **Home (`/`)**: Hero section with interactive metrics preview, stats ticker, 6 flagship service cards, AI SEO interactive showcase, Project Cost & ROI Estimator, 4-step Operating System, client case studies, testimonials, and full enquiry form.
- **Services (`/services`)**: In-depth specifications, deliverables, and tech stack toolkits for all services.
- **About Us (`/about`)**: Our story, Ludhiana manufacturing roots, pan-India presence, agency ethos, and team philosophy.
- **Portfolio (`/portfolio`)**: Case studies with category filtering, measurable metrics (ROAS, organic lead growth), and client stories.
- **Pricing (`/pricing`)**: 3 predictable growth retainers (Local Momentum, Growth Catalyst, Enterprise Dominance), detailed deliverable matrix table, and FAQs.
- **Blog (`/blog`)**: Technical articles on Ludhiana B2B SEO, Generative Engine Optimization, Next.js conversion architecture, and Cost-Per-Lead strategy.
- **Contact (`/contact`)**: Dedicated contact page with Ludhiana HQ address, phone, email, operating hours, WhatsApp direct trigger, and interactive enquiry form.
- **API (`/api/contact`)**: Next.js route handler for processing lead enquiries.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS (light theme, modern gradients, responsive design)
- **Icons**: Lucide React
- **Images**: Remote Unsplash high-resolution photography with optimized Next/Image

## 🏃 Getting Started

### Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production
```bash
npm run build
```

### Run Production Server
```bash
npm start
```
